# Report Writing Savings Calculator

An interactive, browser-based calculator that helps law enforcement agencies estimate the time and cost currently spent on report writing, then model the potential savings from AI-assisted report writing over a 5-year or 10-year term.

The calculator starts with per-shift activity, scales by the number of shifts per day, and then summarizes impact monthly, annually, and across the full selected program term.
